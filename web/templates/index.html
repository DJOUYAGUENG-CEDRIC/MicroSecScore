Comment ça fonctionne ?
MicroSecScore construit un graphe de sécurité G0 à partir de vos fichiers, calcule les scores CVE de chaque image Docker, détecte les chemins d'attaque possibles et produit un tableau de bord visuel interactif. Sans simulation : les scores CVE réels sont interrogés via OSV.dev / NVD NIST (nécessite une connexion internet, 3–10 minutes).
